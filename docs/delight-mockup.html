What's added

Rolling number

The result rolls like a register when an input changes. It's CSS only, and the number is still plain text for Google and screen readers.

The drink, drawn

The cup grows with the size, ice fills by percent, and the soda line drops. Each calculator gets its own object: a keg that drains, a bottle that pours, a plate that fills.

Verdict stamp

Healthy pour, Watch it, or Leaking money, plus one line in a bartender's voice. It uses the same 8 to 15% range the page already shows.

The math as a ticket

"Show your math" prints out like a POS receipt. It's the same numbers, but people screenshot receipts and share them.
